# Tasks

Work in this change's place on its branch, cut from
`bolt/sluice-merges-as-the-boomdrive-app`, which is its base. A test
with no `tools` feature runs directly; a test of the `tools` feature
runs through `sluice exec bolt/sluice-merges-as-the-boomdrive-app -- …`,
as CLAUDE.md's Running checks has it. No test reaches GitHub, the
user's git configuration or a credential: the fakes of GitHub's API in
`crates/sluice/tests/profiles/forge.rs` and
`crates/sluice/tests/profiles/forge/github.rs` answer every call, and
each test's host state is a scratch directory of its own. The decision
is recorded: record 0019's section "The build's choices within the
amendment of 2026-11-18" and rule core.43. Commit by pathspec, with
Conventional Commits subjects scoped to the part of the tree touched,
citing record 0019 as amended 2026-11-18 and rules core.1, core.2 and
core.43 by id.
