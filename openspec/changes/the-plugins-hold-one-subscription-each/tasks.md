# Tasks

Each check runs through sluice: `sluice exec main -- moon run <project>:<task>`. A herdr test is a `fresh '<name>'` case of `plugins/herdr/tests/run.sh`, which the tasks `herdr:test-sh` and `herdr:test-dash` run, each under `tests/leaks.sh`, so a test that leaves a process fails. A board test is a `test("<name>")` of `plugins/sluice-board/tests/register.test.tsx`, which the task `sluice-board:test` runs under the pinned engine.
