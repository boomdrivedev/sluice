# Tasks

Each check runs through sluice: `sluice exec main -- <command>`. A herdr test is a `fresh '<name>'` case of `plugins/herdr/tests/run.sh`, which the tasks `plugin-herdr:test-sh` and `plugin-herdr:test-dash` run, each under `tests/leaks.sh`, so a test that leaves a process fails. A board test is a `test("<name>")` of `plugins/sluice-board/tests/register.test.tsx`, which the task `plugin-board:test` runs under the pinned engine. A crate test is a test of `crates/sluice-core/src/overview.rs`, which the task `core:test` runs.
