# Tasks

Work in this change's place on
`change/a-runs-life-is-written-first-and-actions-runs-its-checks`, cut from
`bolt/sluice-is-refactored-and-runs-on-pools`, which is its base and its gate
(S66). Read the proposal, the design and the delta specs first, then records
0119, 0122 and 0124 and `docs/architecture/core.md`. Each task leaves the tree
building and its named check passing. A quick unit or conformance test runs
directly with `cargo test`; a test that starts git, a process or the binary
runs through sluice against the base, as CLAUDE.md's "Running checks" has it:
`sluice exec bolt/sluice-is-refactored-and-runs-on-pools -- cargo test …`. A
filter after the test target runs each test whose name holds it. New
conformance tests of a run's life go in a new target,
`crates/sluice-conformance/tests/run_life.rs`, with two harnesses: `signed()`,
whose policy names `[signers.box]` and `remote = "origin"` as `peers.rs`'s
`peers()` has it, and `local()`, a branch in the host's own files. Tests use
scratch repositories and a bare clone standing for the remote, never the
host's own sluice state; every git call a test makes runs with no credential
helper and no prompt. A test named as rewritten keeps its name unless a new one
is given. Commit by pathspec, Conventional Commits scoped to the part of the
tree (`core`, `seams`, `fakes`, `records`, `places`, `forge`, `cli`, `site`,
`docs`), citing the clauses, records 0119, 0122 and 0124, rules by id and the
design's decisions by D-number.
