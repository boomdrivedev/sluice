`bolt/sluice-checks-and-waits-on-an-agents-own-work`, the base every
check below runs against. Run suites through sluice, as CLAUDE.md's
Running checks has it; a quick `cargo check`, `cargo clippy` or one
unit test may run directly. Commit by pathspec, Conventional Commits,
scoped to the part of the tree, citing clauses by number and rules by
id. The exec scenarios use `crates/sluice/tests/exec.rs`'s
`moon_setup`, whose projects `a` and `b` each have a `test` task tagged
`gate`, the gate of `bolt/x`.
