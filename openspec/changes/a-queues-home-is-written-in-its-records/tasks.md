# Tasks

Work in this change's place on `change/a-queues-home-is-written-in-its-records`,
cut from `bolt/sluice-is-refactored-and-runs-on-pools`, which is its base and
its gate (S66). Each task leaves the tree building and its named check
passing. A quick unit or conformance test runs directly with `cargo test`; a
test that starts git, the binary or a host process runs through sluice against
the base, as CLAUDE.md's "Running checks" has it: `sluice exec
bolt/sluice-is-refactored-and-runs-on-pools -- cargo test …`. A filter after
the test target runs each test whose name holds it. New conformance tests of a
move go in a new target, `crates/sluice-conformance/tests/homes.rs`, on a
harness whose policy names `[signers.box]` and `remote = "origin"`, as
`peers.rs`'s `peers()` has it. Tests use scratch repositories and a bare clone
standing for the remote, never the host's own sluice state. Commit by
pathspec, Conventional Commits scoped to the part of the tree (`core`,
`seams`, `fakes`, `records`, `cli`, `site`, `docs`), citing the clauses,
record 0122, rules by id and the design's decisions by D-number. A test named
as rewritten keeps its name unless a new one is given.
